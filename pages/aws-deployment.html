AWS Deployment

  1. Create AWS account
  2. Launch EC2 instance (Ubuntu)
  3. Configure Security Group (Port 22, 80)
  4. SSH into instance: ssh -i YOUR_SSH_KEY ubuntu@YOUR_EC2_PUBLIC_IP
  5. Install Docker
  6. Clone repository
  7. Run Docker container
